# Raw Material Guide

A folder-by-folder index of the 29 source-document folders in `FinAdvisor_Training/`. Each top-level folder is now organized into descriptive subfolders. Each table lists the subfolder name, file count, and the kinds of documents it contains.

**Note on text extractions:** Most folders previously contained `.txt` extractions of their PDFs. Those matching `.txt` files have been deleted to reduce duplication. A small number of TXT-only files (no PDF counterpart) remain in folders 01, 04, 06, and 08 — these are sources that were never available in PDF form. See the orphan summary at the end of this guide.
